# Zero D-Rift Plan

1. Read ver3, roadmap, active context, relevant ADRs and the current/next phase only.
2. Preserve rolling-wave planning: detail the current phase and at most outline
   the next; do not generate all future specs.
3. Define goal, user value, dependencies, acceptance scenarios and explicit
   negative boundaries.
4. Add learning objectives and a bounded micro-lab for unfamiliar technology.
5. Break work into 2–4 hour parent tasks and 15–60 minute subtasks with target
   files, verification tier and evidence.
6. Add cost/security/teardown consequences and teach-back questions.
7. Mark assumptions and unresolved decisions; never silently invent versions,
   prices, quotas, metrics or observed results.
8. Request owner review before materially new implementation begins.
