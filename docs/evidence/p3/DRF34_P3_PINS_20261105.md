## 3. CRD đọc từ bản pin (provider v2.8.1, Crossplane v2.4.3, kro v0.9.4)

**S3 bucket (D5):** `buckets.s3.aws.m.upbound.io`, version `v1beta1` (served, storage),
**scope Namespaced**. `spec.forProvider.region` bắt buộc. Bản cluster-scoped cũ
`s3.aws.upbound.io` (v1beta1/v1beta2) vẫn có nhưng **không dùng**.

**Xóa/giữ (D6):** bucket namespaced **không có `deletionPolicy`**. Chỉ có
`spec.managementPolicies`, enum `Observe | Create | Update | Delete | LateInitialize | *`,
mặc định `['*']`.
- Mặc định `*`: xóa MR thì xóa bucket AWS.
- Bỏ `Delete` (ví dụ `[Observe, Create, Update, LateInitialize]`): xóa MR thì **giữ** bucket.
  Đây là cách làm phép thử orphan của D6. Field này ghi "beta, bật mặc định".

**ProviderConfig (D4):** `ClusterProviderConfig` (scope Cluster) và `ProviderConfig`
(Namespaced) thuộc `aws.m.upbound.io`. MR mặc định trỏ `kind: ClusterProviderConfig,
name: default`. `spec.credentials.source` enum có **`IRSA`** (cùng `None`, `Secret`,
`WebIdentity`, `PodIdentity`, `Upbound`).

**ServiceAccount cho IRSA:** Crossplane v2.4.3 có `DeploymentRuntimeConfig`
(`pkg.crossplane.io/v1beta1`) với `serviceAccountTemplate`. Đặt tên SA cố định
`provider-aws-s3` và annotation role ARN → trust subject cố định
`system:serviceaccount:crossplane-system:provider-aws-s3`.

**kro RBAC:** chart v0.9.4 có `rbac.mode`: `unrestricted` (mặc định, toàn quyền cluster)
hoặc `aggregation` (quyền tối thiểu + ClusterRole gắn nhãn
`rbac.kro.run/aggregate-to-controller: "true"`). **Chọn `aggregation`**, với một
ClusterRole chỉ cho `apps/deployments`, `serviceaccounts` và
`s3.aws.m.upbound.io/buckets`.

## 4. Sizing (D7)

Số liệu mặc định đọc được: Crossplane core request 100m/256Mi, limit 500m/1024Mi;
rbac-manager request 100m/256Mi, limit 100m/512Mi. Argo CD install manifest không
đặt request. Upjet provider thường dùng vài trăm MiB.

Ước tính: tổng controller ≈ 2–2,5 GiB RAM; số Pod ≈ 17 (Argo 7, Crossplane 2,
provider 2, kro 1, hệ thống 4, Deployment test 1), dưới trần 29 Pod của m6i.large
(8 GiB, 2 vCPU). **D7 tạm chốt 1 node.** Số đo thật lấy từ lab kind (T2) bằng
`docker stats`; nếu tổng > 5 GiB thì đổi sang 2 node cho window.
